# Original placeholder art

`cat.svg` is the original cat body made for this repository; reusable original
face overlays live in `scripts/cat_reactions.gd`. The room, furniture, weather,
fish snack, meteor, smoke, and comic effects are drawn with Godot's built-in 2D
shapes in `scripts/world_view.gd`. This art uses the repository's licensing terms.
No cat meme photos, platform assets, scraped creator art, or audio are included.

The bundled, unmodified `fonts/ZCOOLKuaiLe-Regular.ttf` is the **ZCOOL KuaiLe**
typeface, Copyright 2018 The ZCOOL KuaiLe Project Authors. It is distributed under
the SIL Open Font License 1.1; the full license is in `fonts/OFL.txt`.
Source: [Google Fonts / ZCOOL KuaiLe](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile).
The font is bundled so Chinese event banners work offline on both desktop
platforms, without relying on installed system fonts.
